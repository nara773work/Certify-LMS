# 調査の足取り
コントローラーでの予約画面では、コーチの面談に一意制約を設けることで二重予約を防ぐ仕様になっていることが確認できた。
ここで、本当にDBカラムに一意制約が課されているか確認したところ、課されていないことが判明した。以下のコードを実装し、このバグを修正する。

```bash
// 同一コーチ・同一日時の二重予約をDBレベルで禁止
$table->unique(['coach_id', 'scheduled_at']);
```
