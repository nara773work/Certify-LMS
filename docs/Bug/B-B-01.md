チケットID：B-B-01 
コーチが、担当教材の教材管理画面にアクセスすると403が返るエラーを修正し、
担当教材のみ、教材管理画面に正常にアクセスすることができる。

Routeから、どのcontroller、Policyがどの操作に紐づいているかを調査する。

本機能を実装するために変更ファイルは以下の通りである。

- 教材画面管理：資格マスタの教材階層（partPolicy）
- その配下にsection(sectionPolicy)
- 出題分野マスタ（QuetionCategoryPolicy）
- 演習問題（sectionquestionPolicy）

それぞれCoachがfalseになっていたので以下の条件に定義しなおす

```bash
UserRole::Coach => $certification->coaches->contains('id', $auth->id),
```


# 実装機能
- 担当コーチは資格マスタ管理一覧に表示されている資格を閲覧することができる
- partの閲覧、作成、編集、削除、公開、非公開が実行できる
- Chapterの閲覧、作成、編集、削除、公開、非公開が実行できる
- Sectionの閲覧、作成、編集、削除、公開、非公開が実行できる
- 演習問題の閲覧、作成、編集、削除、公開、非公開、並び替えを実行できる
- 出題分野マスタの閲覧、作成、編集、削除が実行できる
- 担当コーチ以外は操作ができない

## テスト
- 担当コーチ、管理者は教材管理画面を閲覧できる
- 担当コーチ、管理者はpart,Chapter,Sectionの作成、編集、削除、公開、非公開が実行できる
- 担当外コーチは上記のことが実行できない
- 担当コーチ、管理者は演習問題の閲覧、作成、削除、公開、非公開、並び替えが実行できる
- 担当外コーチは上記のことが実行できない
- 担当コーチ、管理者は出題分野マスタの閲覧、作成、編集、削除が実行できる
- 担当外コーチは上記のことが実行できない
