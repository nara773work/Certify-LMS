# googleカレンダー
- 未連携なら空配列
- 連携済みなら予定取得
- アクセストークン切れならリフレッシュして再取得
- リフレッシュトークン切れなら空配列
- リフレッシュ失敗なら空配列
- グーグルカレンダーへの面談作成
- 未連携なら作成しない
- グーグルカレンダーのイベント削除
- イベントIDがなければ削除しない
- 連携状態判定
- GoogleCalendarGateway をMockeryで差し替えているので、Google APIへの実通信は発生しない

- Google Calendar連携開始 → Google認証画面へリダイレクト
- Google認証callback → トークン保存
- callbackに code がない → 400
- Google Calendar連携解除 → トークン削除

# Gemini
- 正常な応答を返す
- Gemini APIエラー時に例外を投げる
- 空の応答なら空文字を返す
- 一時的なエラー後にリトライして成功する
- Geminiへの送信内容が正しい

# strip
- 正規署名 → 受信・Payment作成・面談回数加算
- 不正署名 → 400で拒否
- 署名なし → 400で拒否
- 同じWebhook → 二重処理されない（冪等性）
