# 実装内容
- 通知一覧APIを構築
- Sanctum Cookie認証でAPIを保護
- 認証ユーザー本人の通知のみ取得
- 他ユーザーの通知IDにはアクセスできないよう制御
- 通知の単一既読化APIを実装
- 通知の全件既読化APIを実装
- TopBarのベルクリックでポップオーバーを開閉
- 通知一覧をAPIから取得して表示
- 「全件」「未読」のタブ切り替え
- 未読タブに未読件数を表示
- 通知本文のプレビューを表示
- 通知日時を「○分前」「○時間前」などで表示
- 通知がない場合の空状態を表示
- 「すべての通知を見る」から通知一覧画面へ遷移
- 未読通知の背景を強調
- 未読件数をJSで動的に集計
-「全件既読」で全通知を既読化
- 通知クリック時に既読化する処理を実装
- 受講生・コーチには通知ポップオーバーを表示
- 管理者がベルを押してもポップオーバーは開かない
