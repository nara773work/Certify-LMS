# テーブル設計
- qa_thread
$table->id();
$table->foreignUlid('certification_id')
    ->constrained()
    ->cascadeOnDelete();
$table->string('title');
$table->text('body');
$table->foreignUlid('user_id')
    ->constrained()
    ->cascadeOnDelete();
$table->string('status')->default('unresolved');
$table->timestamps();

・id：質問を識別するための主キー。
・certification_id：関連する資格名を取得するための外部キー。1対多のリレーションを持つ。
・title：質問のタイトル。タイトルなのでstring型のmax:255に設定。
・body：質問の内容。内容はmax:5000字であることを考慮してtext型に設定。
・user_id：質問を投げたユーザーIDを取得するための外部キー。ユーザーの退出後も質問が残るようにnullOndeleteを設定。
・status：解決済み・未解決を決めるためのカラム。デフォルトはunresolvedに設定。
・timestamp：作成日時と投稿日時用のカラム。

- replay
$table->id();
$table->foreignId('qa_thread_id')
    ->constrained()
    ->cascadeOnDelete();
$table->text('body');
$table->foreignUlid('user_id')
    ->constrained()
    ->nullOnDelete();
$table->timestamps();

・id：回答を識別するための主キー。
・qa_thread_id：回答に対する質問を取得するための外部キー。質問が削除されたときに、その回答も削除されるようにcascadeondeleteを設定。
・body：回答の内容。内容はmax:5000字であることを考慮してtext型に設定。
・user_id：回答を投げたユーザーIDを取得するための外部キー。ユーザーの退出後も回答が残るようにnullOndeleteを設定。
・timestamp：作成日時と投稿日時用のカラム。

# フラッシュメッセージ
作成時：質問を作成しました、回答を作成しました
更新時：質問を更新しました、回答を更新しました
削除時：質問を削除しました、回答を削除しました
削除できなかった時：紐づいている回答があるため削除できません
解決済みに更新：解決済みに変更しました
解決済みにできなかった時：回答がないため解決済みにできません
未解決に更新：未解決に更新しました

# 確認事項
- それぞれのリダイレクト先は問題ないか
- フラッシュメッセージはこれで問題ないか
- certification_idの外部キーにcascadeOnDeleteにしたが問題ないか。
- user_idの外部キーにcascadeOnDeleteにしたが問題ないか。
- qa_thread_idの外部キーにcascadeOnDeleteにしたが問題ないか。
- テーブル設計はこれで問題ないか。
- threadは紐づく回答がある場合は削除できない、という仕様で問題ないか
- 回答数が0の状態では解決済みにできない仕様になっているが問題ないか
- コーチとして、担当資格の未対応スレッドとは、回答数が0のスレッドではなく、未解決スレッドのことだという認識であっているか
- Adminは紐づいている回答関係なく削除できるようにする仕様で問題ないか
