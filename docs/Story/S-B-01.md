# 設計判断
チャット機能を参考に本機能を実装した。
チャット機能はコーチと受講生がテキストでやり取りする機能であり、1on1で、外部には内容が公開されない仕組みである。
これを、多on多（回答者も閲覧者も複数）で、内容が公開される仕組みに変更すればよいと考えたためである。

本機能を実装するために新しく追加したファイルは以下の通りである。
- QaBoardController
- qathreads_table
- QathreadsSeeder
- QaThreadsModel
- QaThreadPolisy
- QaThreadStatus

- QaReplayController
- replies_table
- replaiesSeeder
- repliesModel

# 実装
実装した機能を以下にまとめる
- index画面の表示
- 質問作成画面への推移
- 質問新規作成画面表示
- 質問がDBに保存され、indexにリダイレクトされる
- 未解決・解決済みで条件を絞ることができる
- 資格ごとに表示させることができる
- キーワードで検索することができる
- 質問の詳細画面表示
