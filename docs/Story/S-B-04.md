# 概要
チケットID：S-B-04

自分に送られてきた「チャット」「質問掲示板ので質問に対する回答」「面談の予約」が起きた際に通知が発火される

本機能を実装するために新しく追加したファイルは以下の通りである。
- NotificationController
- NotificationPolicy
- Notification_table
- NotificationModel
- NotificationStatus

# 実装機能
実装した機能を以下にまとめる
- 通知一覧表示画面
- 10件ずつのページネーション取得
- 通知の既読化
- 未読だけ表示
- 通知全件を一度に既読化
- 通知を押すと該当画面への推移と既読化が同時に走る
- 面談を予約した際に、自分とコーチへの通知発火
- 質問掲示板で自分の質問スレッドに回答が返ってきたときに通知発火
- チャットに新規メッセージが届いたときに通知発火
