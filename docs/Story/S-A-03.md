# 実装内容
- 公開中の面談パック一覧を閲覧できる(名前 / 面談回数 / 価格)
- 面談パックを選んで Stripe の外部決済画面へ進み、決済する
- 決済完了後は完了画面が表示され、ダッシュボードへ戻れる導線がある
- 決済をキャンセル / 中断した場合は、残数が変わらない
- 学習中でない受講生は購入できない
- 決済サービスから送られてくる決済結果の通知を受け取る公開窓口を用意し、通知が改ざんされていないか検証する
- 決済結果の通知に応じて、完了した購入の分だけ残面談回数を加算する
- 決済サービスからの通知が重複して届いても、残数の会計が崩れない
- 残数が加算された瞬間から、受講生の残数(ダッシュボード / 予約画面の数値)に反映される

# シーダー
デモ受講生
- 1回パック購入完了
- 5回パック購入保留
- 10回パック購入失敗

固定受講生（受講生花子）
- 10回パック購入失敗
