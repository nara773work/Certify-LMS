# 概要
チケットID：B-B-02

管理者はプランパック管理画面からCRUDできるようにし、受講生側に表示されるプランパックを運営側でコントロールできるようにする。

本機能を実装するために新しく追加したファイルは以下の通りである。
- PlanController
- PlanRequest
- PlanPolicy

# 実装機能
実装した機能を以下にまとめる
- index画面の表示　
- ステータスでも条件絞り
- キーワード検索
- アック業に契約中の受講生数を表示
- 10件ずつのページネーション取得
- 詳細情報の表示（基本情報・紐づく受講者一覧・メタ情報）
- 新規作成画面の表示
- Planの新規作成
- Planの編集画面表示
- Planの更新
- 公開済み以外のステータスのSKUの削除
- ステータスを公開に更新する
- ステータスをアーカイブにできる
- ステータスを下書きにできる
- 管理者以外がアクセスすると403エラーを返す

# Request
Plan名:required,max
required:プラン名を入力してください
max:200字以内で入力してください

説明:max
max:2000字以内で入力してください

受講期間:required,between
required:面談回数を入力してください
between:1~3650の範囲で入力してください

初期付与面談回数:required,between
required:初期付与面談回数を入力してください
between:0~1000の範囲で入力してください

並び順:between:0~1000
between:0~1000の範囲で入力してください

アーカイブ化時：アーカイブにしました
下書き化時：下書きにしました
