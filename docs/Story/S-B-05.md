# 概要
チケットID：B-B-05

受講生本人は受講登録配下に個人目標をたてて、目標のURUDや達成・未達成を視覚的に区別できる。

本機能を実装するために新しく追加したファイルは以下の通りである。
- EnrollmentGoalController
- enrollment_goal_table
- EnrollmentPolicy
- EnrollmentGoalSeeder
- EnrollmentGoalPolicy
- EnrollmentRequest

# 実装機能
実装した機能を以下にまとめる
- 目標を10件ずつのページネーション取得
- 目標の新規作成
- 目標の編集画面表示
- 目標の更新
- 目標を達成に更新する
- 目標を未達成に更新する
- 目標の削除
- コーチは担当資格の受講生の個人目標の閲覧
- 管理者は受講生の個人目標の閲覧

# シーディング
受講生花子（固定受講生）
未達成：応用情報、基本情報、TOEIC
達成済み：日商簿記

デモ受講生
未達成：基本情報
達成済み：応用情報、日商簿記2級

# Request
タイトル:required,max
required:プラン名を入力してください
max:50字以内で入力してください

説明:max
max:1000字以内で入力してください

目標期間:'date', 'after:today'
date:有効な日付を入力してください
after:today:本日以降の日付を入力してください

# フラッシュメッセージ

未達成時：個人目標を未達成に戻しました
