# 概要
チケットID：S-B-07

コーチは担当資格の受講生に対して、メモを残すことができる。管理者は任意のメモを操作することができるが、コーチは自分が作成したメモのみ操作することができる。

本機能を実装するために新しく追加したファイルは以下の通りである。
- EnrollmentNoteController
- EnrollmentNotePolicy
- EnrollmentNoteRequest
- enrollment_note_table
- EnrollmentNoteModel
- EnrollmnetSeeder

# 実装機能
実装した機能を以下にまとめる
- メモの作成
- メモの更新
- メモの削除
- 他のコーチのメモの閲覧（閲覧のみ）
- 管理者は任意のメモの操作

# シーディング
| コーチ名 | 資格 | 受講生氏名 | 字数（大体） |
| コーチ太郎 | TOEIC | 受講生花子 | 25 |
| コーチ太郎 | 基本情報 | 受講生花子 | 20 | 
| コーチ太郎 | 基本情報 | 受講生 | 320 | 
| コーチ花子 | TOEIC | 受講生花子 | 780 |
| コーチ花子 | 日商簿記 |  受講生花子 | 80 |
| 管理者 | 日商簿記 | 受講生花子 | 25 |

# test
PlanController
- HTTPメソッドでパスを通すことができる
- 管理者は任意のメモを閲覧、削除、更新、削除できる
- コーチは担当資格のメモを作成、更新、削除できる
- 受講生は403エラーが返される
- バリデーションを通過したデータはDBに保存される
- バリデーションを通過しなかったデータはDBに保存されない
- 削除したデータはDBから削除される
- バリデーションテスト
