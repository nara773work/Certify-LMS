# 概要
チケットID：B-B-02

管理者は面談パック管理画面からCRUDできるようにし、受講生側に表示される面談パックを運営委側でコントロールできるようにする。

本機能を実装するために新しく追加したファイルは以下の通りである。
- MeetingPackController
- MeetingRequest
- MeetingPolicy
- PaymentStatus

# 実装機能
実装した機能を以下にまとめる
- index画面の表示　
- ステータスでも条件絞り
- キーワード検索
- 並び順の小さい順に一覧表示
- 10件ずつのページネーション取得
- 詳細情報の表示（基本情報・直近の購入者・メタ情報）
- 新規作成画面の表示
- SKUの新規作成
- SKUの編集画面表示
- SKUの更新
- 公開済み以外のステータスのSKUの削除
- ステータスを公開に更新する
- ステータスをアーカイブにできる
- ステータスを下書きにできる
- 管理者以外がアクセスすると403エラーを返す


# シーディング
- PaymentSeeder
1回パック：受講生花子
金額3000円、回数1回、支払い済みステータス、本日より10日前に支払い済み

# test
- MeetingPackController
- HTTPメソッドでパスを通すことができる
- 管理者のみアクセスできる
- 受講生・コーチはアクセスしても拒否される（403エラー）
- ステータスで条件を絞ることができる
- 本文に含まれる文字でキーワード検索を行うことができる
- SKUを新規作成画面が表示される
- バリデーションを通過したデータはDBに保存される
- バリデーションを通過しなかったデータはDBに保存されない
- 詳細画面が表示される
- 編集画面を表示することができる
- 更新することができる
- ステータスが公開済み以外のSKUを削除することができる
- 削除したデータはDBから削除される
- ステータスが下書きのSKUのステータスを公開済みに変更できる
- ステータスが公開済みのSKUのステータスをアーカイブに変更できる
- ステータスがアーカイブのSKUのステータスを下書きに変更できる

# Request

required:SKU名を入力してください
max:255字以内で入力してください

説明:max
max:2000字以内で入力してください

面談回数:required,min,max
required:面談回数を入力してください
between:1~100の範囲で入力してください

価格:required,min,max

# フラッシュメッセージ

アーカイブ化時：アーカイブにしました
下書き化時：下書きにしました
