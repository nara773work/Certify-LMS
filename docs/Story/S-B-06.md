# 概要
チケットID：B-B-06

プロフィール画面のメールアドレス以外を更新することができる。また、コーチのみ固定面談URLを変更することができる。

本機能を実装するために新しく追加したファイルは以下の通りである。
- ProfileController
- ProfileRequest
- AvatarRequest
- PasswordRequest

# 実装機能
実装した機能を以下にまとめる
- メールアドレス以外のプロフィールの更新
- アバター画像のアップロード
- パスワードの更新

# シーディング


# test
PlanController
- HTTPメソッドでパスを通すことができる
- 管理者、コーチ、受講生本人はプロフィール編集画面を閲覧できる
- 本人はプロフィールの更新ができる
- 本人はメールアドレスの更新はできない
- バリデーションを通過したデータはDBに保存される
- バリデーションを通過しなかったデータはDBに保存されない
- 本人はアバターを削除することができる
- 削除したデータはDBから削除される
- 本人はパスワードを更新することができる
- バリデーションテスト

# テーブル設計
なし

# Request
- Profile
タイトル:required,max,string
required:氏名を入力してください
max:255字以内で入力してください
string:文字形式で入力してください

自己紹介:max,string
max:1000字以内で入力してください
string:文字形式で入力してください

- Avatar
アバター:image,mimes:jpeg,png,webp,max:2048
image:画像形式で登録してください
mimes:jepg,png,webpで登録してください
max:2MB以内で登録してください

- Password
現在のパスワード:required, current_password
required:現在のパスワードを入力してください
current_password:現在のパスワードを入力してください

新しいパスワード:required,min:8
required:パスワードを入力してください
min:8字以上で入力してください

確認用パスワード:required,confirmed
required:確認用パスワードを入力してください
confirmed:確認用パスワードが一致しません

# フラッシュメッセージ
更新時：プロフィールを更新しました
アバター登録時：アバターを登録しました
削除時：アバターを削除しました
パスワード更新時：パスワードを更新しました

# リダイレクト先
作成時：settings.profile.edit
更新時:settings.profile.edit
削除:settings.profile.edit
達成・未達成時：settings.profile.edit
