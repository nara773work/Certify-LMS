GoogleカレンダーとLMSを連携させることで外部との予定で面談が実施できない時刻の面談スケジュールを非表示にできる

以下の手順でGoogleカレンダーを連携させる
- Google Calendar APIを有効にする
- OAuthスコープを設定する(http://localhost:8000/auth/google/callbackがリダイレクト先URL)
- .envファイルにIDとシークレットを設定する
- 以下のコマンドでライブラリを入れる
```bash
composer require google/apiclient
```
- コントローラー、ルートを作成する

# シーディング
|コーチ名|連携有無|
|コーチ太郎|連携済み|
|コーチ花子|未連携|

# テーブル設計
Schema::create('google_calendar_tokens', function (Blueprint $table) {
    $table->id();
    $table->foreignUlid('user_id')
        ->constrained('users')
        ->cascadeOnDelete();
    $table->string('access_token');
    $table->string('refresh_token');
    $table->timestamp('expires_at');
    $table->timestamp('refresh_token_expires_at');
    $table->timestamps();
});
