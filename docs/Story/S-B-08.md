# 概要
チケットID：S-B-08

運営側が受講生全体・資格別・ユーザー別にそれぞれお知らせ通知を発火することができる。

本機能を実装するために新しく追加したファイルは以下の通りである。
- AnnouncementController
- AnnouncementPolicy
- AnnouncementRequest
- announcements_table
- AnnouncementModel
- AnnouncementSeeder

# 実装機能
実装した機能を以下にまとめる
- お知らせ一覧を表示できる
- お知らせ作成画面が表示できる
- お知らせの作成ができる
- 宛先を受講生全体、資格別、ユーザー別に指定できる
- 詳細画面を表示することができる
- 認証ユーザーのみ通知を受けることができる

# シーディング
全受講生
title:全受講生の方へアクセス制限のお知らせ
body:システムメンテナンスのため、2026.09.10の13:00~15:00はアクセスが制限されます

資格別（基本情報受講生宛て）
title:基本情報を受講の方へお知らせ
body:基本情報の講座が更新されました。

ユーザー別（受講生花子宛）
title:受講生花子さんへ不具合解消のお知らせ
body:先日報告していただいた不具合を解消しましたのでお知らせいたします。ご不便をおかけいたしました。
